# Test-video production plan — the full 4-minute presentation, shot and cut

Goal: a realistic, complete run of the presentation as a video — rehearsal
artifact today, template for the real thing. **No real orders in this cut**:
the whole flow runs in mock mode (that's what the bridge spec's mock modes
are for — "the entire flow testable with zero external services"). The
audience must not be able to tell.

Footage and cuts live in **Amperstrand/test-video** (private). Plans live
here in `presentation/`. Repo layout: `footage/` (raw), `cuts/` (timed
edits), `slides/` (frames), `README.md` (status + what's still missing).

## On-screen characters (single speaker, two labels)

- **ALICE** = numo terminal footage, persistent "ALICE" corner tag. If
  possible, one steady device setup for every Alice shot so the terminal
  feels like one continuous session.
- **BOB** = bridge view (worker dashboard / log tail / config), persistent
  "BOB" tag. The moment Bob "becomes Burgermeister" is a label flip on
  screen: same bridge view, tag changes to "BOB — BURGERMEISTER".
- No actors needed; labels do the casting. Optional: 2-second intro cards
  (typographic, no faces — keeps it clean and reproducible).

## Audience QR (the live-all-day surface)

- [ ] Decide target: deployed mock-mode bridge URL (public worker) vs a
      landing page that embeds numo + Bob preloaded — landing page is safer
      and prettier
- [ ] Stable short URL; QR generated offline, high contrast, white border
- [ ] **Deploy it before the talk and leave it running all day** — the QR
      is a promise; scanning a dead link on stage is the worst failure mode
- [ ] Test scan from the back of the room, and with two phones
- [ ] Rate-limit / mock-mode guard on the public surface (no real orders
      today, and no runaway costs)

## Edit plan (two cuts + one master)

1. **Main cut (4:00):** the whole presentation — cards, order run, prompt
   reveal, map, honesty, QR close. This is the test video.
2. **Order-run cut (55 s):** S4–S8 alone, for reuse and testing.
3. **Master with speaker:** single speaker narrates over the main cut,
   recorded to picture, stopwatch-checked. Rehearse until ≤ 4:00.

Music: pulse under the order run, ducked under speech. No fake LIVE badge,
no fake timestamps — mock-realistic, not deceptive.

## Hygiene (same rules, mock or not)

- DND on, clean status bars, no personal notifications, no real npubs, no
  card footage ever (mock mode makes this trivial — that's the point).
- Push raw footage to Amperstrand/test-video as you shoot; nothing lands in
  public jamezz.
